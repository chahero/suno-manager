How to get Bearer Token

  1. Log in to SUNO website (suno.com)
  2. Open browser developer tools (F12)
  3. Select the Network tab
  4. Refresh the page (F5)
  5. Click on any request starting with feed or api
  6. Find authorization in Request Headers
  7. Copy the entire Bearer eyJ... value
  8. Paste it in the input field above
Tip: You can include or exclude the "Bearer" prefix. It will be handled automatically.

This token is stored on the server and will be deleted when you log out
